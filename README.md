## 📌 نبذة عن المشروع / Overview

* **بالعربية:** تعتمد أداة **AI Phishing & Threat Analyzer** على نماذج الذكاء الاصطناعي التوليدي لتحليل الاتصالات المشبوهة. تم بناؤها خصيصاً لفرق مراكز العمليات الأمنية (SOC) والدفاع المؤسسي لفحص نصوص الإيميلات والروابط واستخراج تقييم مخاطر دقيق وتوصيات أمنية.
* **In English:** The **AI Phishing & Threat Analyzer** leverages generative AI to analyze suspicious communications. Built for Security Operations Center (SOC) teams and enterprise defense, it parses email context to generate instant threat assessment reports.

---

## 🚀 المميزات الرئيسية / Key Features

| الميزة / Feature | الوصف بالعربية | Description (EN) |
| :--- | :--- | :--- |
| 🎯 **Risk Scoring** | تقييم مستويات الخطر فورياً (منخفض، متوسط، حرج) مع نسبة الثقة | Assigns immediate threat levels (Low, Medium, Critical) |
| 🔍 **Indicator Extraction** | استخراج الروابط الخبيثة، النطاقات المزيفة، وصيغ التهديد | Identifies deceptive URLs, spoofed domains & urgent phrasing |
| 🛡️ **Mitigation Steps** | توليد خطة استجابة سريعة للحوادث الأمنية وفرق الـ SOC | Generates actionable remediation protocols for incident responders |
| ⚡ **REST API Integration** | تنفيذ ألترا سريع بدون استهلاك موارد الجهاز المحلي | Ultra-fast execution with zero heavy local dependencies |
